# 📝 My To-Do

A responsive **To-Do List web application** built with **HTML, CSS, and Vanilla JavaScript**. The project demonstrates DOM manipulation, form validation, event handling, and responsive layouts using CSS Flexbox and Grid.

## ✨ Features

* ⚡ **Quick Add** — Add a task instantly using the top input field.
* 📋 **Add Task Details** — Add a task with:

  * Task name
  * Due date
  * Optional notes
* ✅ **Form Validation** — Displays inline error messages for missing or invalid required fields.
* 🗑️ **Delete Tasks** — Remove tasks easily using the delete button.
* 📱 **Responsive Design** — Works across desktop, tablet, and mobile screens.
* 🎨 **Modern UI** — Uses pill-shaped inputs and buttons with a clean layout.
* 🧩 **Dynamic DOM Manipulation** — Tasks are created and removed dynamically using JavaScript.

## 💻 How to Use

### Quick Add

1. Enter a task in the **Quick Add** input field.
2. Click **Add**.
3. The task will appear in the to-do list.

### Add Task Details

1. Enter a **task name**.
2. Select a **due date**.
3. Add optional **notes**.
4. Submit the form.
5. The task will be added to the list after successful validation.

### Delete a Task

Click the 🗑️ button next to a task to remove it from the list.

## 📱 Responsive Design

The application uses:

* **CSS Flexbox** for the navigation bar.
* **CSS Grid** for the main content layout.
* **Media queries** to adapt the interface for smaller screens.

This allows the application to provide a consistent experience on desktop, tablet, and mobile devices.
